## 5. Tarification — Pourquoi 0.12 / 0.18 ETH ?

| Prix    | Justification |
| ------- | ------------- |
| 0.12 ETH (~360€) Whitelist | Prix d'entrée d'un collectionneur crypto sérieux. Sous 100€ = pas crédible pour une pièce 1-of-1. |
| 0.18 ETH (~540€) Public | +50% sur whitelist = incite à postuler. Aligné sur les drops 1-of-1 d'artistes émergents reconnus. |
| Patron Founder (sur invitation) | 3 Gardiens groupés + œuvre physique = ticket d'entrée institutionnel ~5 000€. |

**Si tu as 0 collectionneur connu** : descends Whitelist à 0.08 ETH, Public à
0.12 ETH. Mieux vaut sold-out à 0.08 que floor cassé à 0.18.

**Total potentiel revenu primaire** : 0.18 × 5 = 0.90 ETH (~2 700€), plus
royalties 7.5% à vie sur reventes secondaires. L'objectif n'est pas la marge
primaire — c'est la base installée pour la Saison II.

## 6. Risques & mitigations

| Risque | Mitigation |
| --- | --- |
| **Personne ne vient au mint** | Whitelist sélectionnée à la main, validée 48h avant. Si <10 candidatures qualifiées, on **repousse** plutôt qu'on flop. |
| **Critique d'appropriation culturelle** | Inviter un consultant culturel (Yoruba ou Akan) à valider le storytelling. Mentionner les sources avec respect. |
| **Pirates/copies des visuels** | Watermark discret + dépôt INPI des visuels avant mint. Réservation noms de domaine .xyz/.art. |
| **Frais gas trop élevés** | Base L2 = quelques centimes par mint. Pas Ethereum mainnet. |
| **Wallet du studio compromis** | Multi-sig 2/3 obligatoire (Gnosis Safe). Pas de seed phrase numérique. |
| **Hype morte après le mint** | Saison II conditionnelle annoncée → garde un horizon ouvert sans promettre. |
